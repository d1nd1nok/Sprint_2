### Задание 3. Очки для спортсменов

Нужно написать три класса — разные способы начислять спортсменам очки:

1. `PointsForPlace` — очки за занятое место.
2. `PointsForMeters` — очки за расстояние, на которое спортсмен метнул диск.
3. `TotalPoints` — учитывает и место, и расстояние.

#### `PointsForPlace`

Метод `get_points_for_place(place)` принимает целое число `place` и возвращает `points` (изначально `0`):

| Условие | Результат |
|---------|-----------|
| `place > 100` | сообщение `'Баллы начисляются только первым 100 участникам'` |
| `place < 1` | сообщение `'Спортсмен не может занять нулевое или отрицательное место'` |
| иначе | `points = 101 - place` |

#### `PointsForMeters`

Метод `get_points_for_meters(meters)` принимает целое число `meters` и возвращает `points` (изначально `0`). Например, за 10 метров спортсмен получит 5 очков.

| Условие | Результат |
|---------|-----------|
| `meters < 0` | сообщение `'Количество метров не может быть отрицательным'` |
| иначе | `points = meters * 0.5` |

#### `TotalPoints`

Класс для многоборцев. Наследуется сразу от `PointsForPlace` и `PointsForMeters` и реализует все их методы. Дополнительно содержит:

- метод `get_total_points()`, который принимает аргументы `meters` и `place`;
- переменную `total` — сумму значений `get_points_for_place()` и `get_points_for_meters()`.

Метод возвращает `total`.

> ❗ Подумай, какие методы в этом задании могут быть статическими. Если метод можно сделать статическим — делай.
> Подумай, какая область видимости должна быть у переменной `points` — глобальная или локальная.

Прекод:

```python
class PointsForPlace:
    ...

class PointsForMeters:
    ...

class TotalPoints(PointsForPlace, PointsForMeters):
    ...

points_for_place = PointsForPlace()
print(points_for_place.get_points_for_place(10))

points_for_meters = PointsForMeters()
print(points_for_meters.get_points_for_meters(10))

total_points = TotalPoints()
print(total_points.get_points_for_place(10))

print(total_points.get_total_points(100, 10))
```
